# ROSE Companion 3.4 — complete catalog map annotations

Validated on 2026-10-23. The public application is hosted at
[abeel87.github.io/rose-builds](https://abeel87.github.io/rose-builds/).

## Scope and evidence

All **138 catalog entries** classified as King, SubBoss, Wandering or event now
have a map annotation and an attributed original client-model portrait.
The catalog is a documented reference snapshot, not a certified inventory of
every currently enabled server NPC. The current client contains 260 ranked
King/SubBoss records, including duplicate variants and unused records.

**590 unique point locations for 114 entries** come from 591 source objects in
the current official snapshot `releases/ci-38925666467-1`. The extraction covers
1,544 IFO files in 49 zones. The extra pass found 33 previously omitted entries
and 163 additional positions. Older 2024 Clan Field IDs were not copied over:
the current area 11 uses IDs 4617, 4623, 4629, 4634, 4636 and 4640.

**29 whole-zone annotations cover the other 24 entries.** They have no x/y
coordinate or radius. A dashed frame surrounds the map and named badges let
the player select each boss. Sources distinguish current-client coordinates,
official descriptions and community observations. Images, floors and zone IDs
are checked together; archive layers never inherit current annotations.

The former 95-entry catalog was limited largely to enemies with community drop
tables. The 43 additions consist of 33 entries with current-client placements
and ten documented dungeon encounters. Unknown drop tables are labelled as
unknown, rather than presented as zero possible drops.

## Accuracy decisions

- The official [2026-08-25 patch](https://forum.roseonlinegame.com/topic/7762-patch-notes-2026-08-25-premium/)
  randomized Wandering positions. Six species are shown across their known
  reference zones from [player reports](https://forum.roseonlinegame.com/topic/4095-orlo-kingsboss/).
  The interface discloses that these species-to-zone assignments were not
  reverified after the change. The 16 historical 2025 point observations were
  deliberately excluded from runtime positions.
- Super Hornet has six event zones, combining the original list with the
  [January 2026 additions/removal](https://forum.roseonlinegame.com/topic/7566-patch-notes-2026-01-30-gem-balance-update/)
  and [June 2026 event update](https://forum.roseonlinegame.com/topic/7702-patch-notes-2026-06-15-clan-costume-buff-changes-and-more/).
  Anima Lake is absent; Sunshine Coast uses the Event variant, ID 37.
- Worm Dragon 201 is only tentatively associated with Gorge of Silence from a
  species-level GM description. That uncertainty appears directly on its card
  and map annotation. Giant/Super Worm coordinates are not reused.
- Dungeon encounters use their documented instance. Unlabelled entrance
  screenshots are not treated as evidence for boss rooms.
- Five high-level Birth Island variants have real current-client placements,
  with a visible note that their availability and use on the live server are
  unconfirmed.

## Visuals and navigation

The 43 new 640×640 transparent portraits use original current-client models,
skeletons, body textures and equipped parts. Every output has verified hashes,
valid alpha and clear margins; all were visually inspected. The total added
portrait payload is approximately 1.9 MB. No AI artwork or summoning-item
portrait substitutes are used.

The global King selector opens a map and, where applicable, its matching floor.
Browser verification confirmed Moon Pastor Laguz opens Forgotten Temple B2,
opens its detail card and returns to the same filtered floor. Golden Ring
shows eight ordinary points plus two clearly labelled whole-zone Wandering
annotations, with source notes and supplemental source links.

## Address migration

The primary URL stays on GitHub Pages. The previous Sites publication receives
a separate migration page, not the application payload. Visitors without saves
continue automatically to the new origin with their query and fragment intact.
Visitors with stored builds can download a compatible copy before continuing.
The original localStorage values are never modified or deleted. Changed drafts
are exported as an additional build because the ordinary importer deliberately
preserves the receiving device's current draft. At the 300-build limit the draft
has its own export. A retirement worker clears only old ROSE offline caches.

Thirteen migration scenarios passed against the application's actual
`parseImport` and `mergeLibraries`, including legacy data, malformed JSON,
storage denial and worker-update failure. The Site identity and audience stay
unchanged. Publication status is recorded separately after deployment.

## Mobile verification

The map and global King finder were checked in a 390 px iframe (375 px effective content width). No horizontal document overflow was observed. Selecting Wandering Asper focused its whole-zone annotation and updated the map URL; the badge and map legend remained readable and tappable.
